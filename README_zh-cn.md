# 云竹交通扩展Mod

简体中文 · [English](./README.md)


**云竹交通扩展Mod**是 [Minecraft Transit Railway Mod](https://github.com/jonafanho/Minecraft-Transit-Railway)
的装饰性附加模组，提供精美的**电梯**与**地铁站**元素，以美化您的轨交建造。

<img src="http://image.yunzhu.host/i/2025/05/01/681363e498172.webp" style="width: 200px; height: auto;" />


---

## 功能特色

- 电梯装饰组件 (更多外呼、电梯门，到站灯，智能分配)
- 地铁站美化内容

---

## RongMC 26.3 版本的改动

更新门体背面 UV 与透明渲染。楼层编辑器加入明确的保存按钮，设置可从 Mod Menu 打开，兼容 MTR 的新版电梯实体和可选 Oriel 界面。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/Yunzhu-Transit/releases/tag/v1.0.2-port.1%2B26.3) 下载 **v1.0.2-port.1+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)、[MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway)。 将发行 JAR 放进实例的 `mods/` 目录。 联机双端使用同系列 MTR 和 YTE。可在客户端通过 Mod Menu 找到配置入口；Oriel 外观切换由 RongMC Transport UI 提供。
