# Yunzhu Transit Extension Mod

[简体中文](./README_zh-cn.md) · English


**Yunzhu Transit Extension** is a decorative add-on for
the [Minecraft Transit Railway Mod](https://github.com/jonafanho/Minecraft-Transit-Railway), providing stylish **elevator** and **metro station** elements to enhance your transit builds.

<img src="http://image.yunzhu.host/i/2025/05/01/681363e498172.webp" style="width: 200px; height: auto;" />


---

## Features

- Elevator decorations (Enhanced Call Buttons, More Doors, Hall Lanterns and Destination Dispatch)
- Metro station enhancements

---

## What changed in the RongMC 26.3 port

Back-face UVs and translucent rendering were updated. The floor editor has an explicit save button, with settings available from Mod Menu. The addon works with the port’s lift entities and optional Oriel interface.

## Installation

Download **v1.0.2-port.1+26.3** from [GitHub Releases](https://github.com/OpenRongMC/Yunzhu-Transit/releases/tag/v1.0.2-port.1%2B26.3) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Fabric API](https://modrinth.com/mod/fabric-api), [MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway). Place the release JAR in the instance’s `mods/` directory. Use matching MTR and YTE builds on both sides. Mod Menu provides a client configuration entry, and RongMC Transport UI provides the optional Oriel appearance.
